# Quickstart

Install Rust and Node.js for repository development. All product behavior is built from Rust.

```sh
npm install
npm run build
./bin/deixic-code --version
./bin/deixic-code setup
./bin/deixic-code
./bin/deixic-code serve --port 3000
```

Run checks with:

```sh
npm run check:rust-only-runtime
npm run lint
npm test
```
